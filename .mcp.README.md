# Project MCP config (`.mcp.json`)

This file configures **AgentMemory** for local agent tooling only
(`AGENTMEMORY_URL` → `@agentmemory/mcp`).

It is **not** the FairPay product Agent MCP.

- FairPay product MCP: JWT-gated Edge Function `fairpay-agent-mcp`
- Docs: [docs/fairpay-agent-mcp.md](docs/fairpay-agent-mcp.md), [AGENTS.md](AGENTS.md)
- Do not add FairPay MCP as a static Cursor URL without a per-user Bearer token
