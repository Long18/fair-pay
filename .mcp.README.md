# Project MCP config (`.mcp.json`)

This file configures **AgentMemory** for local agent tooling only
(`AGENTMEMORY_URL` → `@agentmemory/mcp`).

It is **not** the FairPay product Agent MCP.

- FairPay product MCP: JWT-gated Edge Function `fairpay-agent-mcp`
- Docs: [docs/fairpay-agent-mcp.md](docs/fairpay-agent-mcp.md), [AGENTS.md](AGENTS.md)
- Do not add FairPay MCP as a static Cursor URL without a per-user Bearer token

## Supabase MCP (Cursor plugin / `project-0-fair-pay-supabase`)

| Goal | Tooling |
|------|--------|
| Inspect or change **hosted** FairPay project (tables, SQL, advisors, edge deploy) | Supabase MCP namespace (`project-0-fair-pay-supabase` or Cursor Supabase plugin) — uses the linked cloud project |
| **Local** Docker stack (`127.0.0.1:54321` / `54322`) | Supabase CLI: `pnpm db:local:bootstrap`, `pnpm supabase:status`, `docker exec supabase_db_FairPay psql …` — MCP does **not** attach to local Postgres by default |

After local bootstrap, point the app at local API keys in `.env.local` (see [`.env.example`](.env.example) for bank/MoMo preview flags: `VITE_BANK_SETTINGS_PREVIEW`, `VITE_DONATION_WIDGET_PREVIEW`). Do not run `db push` to production from agents without explicit approval (remote migration drift may block apply).
